## 📌 Projetos em Destaque
### 💳 **SimplicityDigitalWallet**  
Uma **carteira digital** desenvolvida em Java com foco em organização financeira pessoal.  
- Funcionalidades: cadastro de usuários, transações, histórico e controle de saldo.  
- Foco: boas práticas de POO e persistência de dados.  
- Tecnologias: Java (POO), MySQL, SpringBoot.  

---

### 📄 **PDFChat**  
Aplicação de **chat com PDFs**, permitindo interação em linguagem natural com o conteúdo de documentos.  
- Funcionalidades: upload de PDF, extração de conteúdo e perguntas/respostas via IA.  
- Foco: integração com **modelos de linguagem (LLMs)** e NLP.  
- Tecnologias: Python, Streamlit, NLP, bibliotecas de IA.  

---

### ⚙️ **Automation_CCT**  
Projeto de automação para carga de contratos de transporte de gás natural.  
- Funcionalidades: leitura de planilhas, integração de dados, criação de backups e interface gráfica para seleção de arquivos.  
- Foco: **automação de processos manuais repetitivos** no setor de energia.  
- Tecnologias: Python (openpyxl, Tkinter, logging), Excel.
